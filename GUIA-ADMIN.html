🍔 Guía de Administración

Aprende a gestionar el menú de Chavos Burger

🚀 Inicio Rápido

⚙️ Abrir Panel Admin 👁️ Ver Menú Público

📖 ¿Cómo Funciona?

El sistema de administración funciona 100% local en tu navegador. Los cambios se guardan en tu dispositivo y para publicarlos debes subir el archivo JSON a GitHub.

ℹ️ Flujo de trabajo 1. Haces cambios en el admin local → 2. Exportas el JSON → 3. Subes a GitHub → 4. ¡Menú actualizado!

Archivos importantes

Archivo Descripción
admin.html Panel de administración (ábrelo en tu navegador)
data/menu-data.json Todos los datos del menú (productos, categorías, config)
index.html El menú público que ven tus clientes

📦 Gestionar Productos

Crear un producto nuevo

  1. Abre el panel de admin Ve a admin.html y asegúrate de estar en la sección "Productos"
  2. Clic en "+ Nuevo Producto" Se abrirá un formulario para llenar los datos
  3. Llena la información Nombre, precio, descripción, categoría, badge (opcional) e imagen (opcional)
  4. Guarda el producto Clic en "Guardar" - el producto aparecerá en la lista

Opciones de imagen

Opción Cuándo usarla
URL Externa Si la imagen está en internet (ej: https://example.com/imagen.jpg)
Ruta Local Si la imagen está en tu proyecto (ej: images/mi-producto.jpg)
Subir Archivo Sube desde tu dispositivo (máx 500KB, se convierte a base64)
💡 Tip Si subes muchas imágenes, es mejor usar URLs externas o rutas locales para que el archivo JSON no se vuelva muy pesado.

📂 Gestionar Categorías

Crear una categoría nueva

  1. Ve a la sección "Categorías" Clic en el menú lateral
  2. Clic en "+ Nueva Categoría" Se abrirá el formulario
  3. Define un ID único Usa letras minúsculas y guiones (ej: postres-especiales)
  4. Agrega nombre, emoji e icono El emoji aparece en el menú, el icono es la imagen de la sección
💡 Tip No puedes eliminar una categoría que tiene productos. Primero mueve o elimina los productos.

Ordenar categorías

Usa los botones ▲ y ▼ en cada tarjeta de categoría para cambiar el orden. Las categorías con menor número aparecen primero en el menú.

🌐 Publicar Cambios en GitHub

📱 → 📥 → 🐙 → ✅

Desde el celular

  1. Haz tus cambios en el admin Edita productos, categorías o configuración
  2. Clic en "Exportar Datos" Se descargará menu-data.json a tu celular
  3. Abre GitHub Usa la app de GitHub o el navegador
  4. Ve a tu repositorio → data/ Navega hasta la carpeta data
  5. Sube/reemplaza menu-data.json En GitHub web: "Add file" → "Upload files"
  6. ¡Listo! GitHub Pages se actualiza automáticamente en 1-2 minutos
✅ Verificar cambios Después de subir, abre tu menú público y verifica que los cambios se aplicaron correctamente.

🔄 Sincronización

¿Qué es "Sincronizar GitHub"?

Este botón descarta todos tus cambios locales y descarga los datos más recientes desde GitHub. Úsalo si:

  • Hiciste cambios en otro dispositivo
  • Quieres descartar cambios que no guardaste
  • El menú local está desactualizado
⚠️ Cuidado Sincronizar borra todos los cambios locales que no hayas exportado. Asegúrate de exportar primero si quieres conservarlos.

🔧 Solución de Problemas

Los cambios no aparecen en el menú público

  1. Verifica que subiste el archivo a GitHub correctamente
  2. Espera 1-2 minutos para que GitHub Pages se actualice
  3. Limpia la caché del navegador (Ctrl+Shift+R o Cmd+Shift+R)

El admin no carga los datos

  1. Verifica que el archivo data/menu-data.json existe
  2. Asegúrate de que el JSON tiene formato válido
  3. Intenta con "Sincronizar GitHub"

Error al subir imagen

Las imágenes deben pesar menos de 500KB. Usa herramientas online para comprimir imágenes grandes.

📄 Estructura del JSON

El archivo menu-data.json tiene esta estructura:

{ "config": { "nombreRestaurante": "Chavos Burger", "slogan": "...", "whatsapp": "573183752974", ... }, "categorias": [ { "id": "burgers", "nombre": "Burgers", ... } ], "productos": [ { "id": 1, "nombre": "Vecindad", "precio": 18000, ... } ], "badges": { ... } }
